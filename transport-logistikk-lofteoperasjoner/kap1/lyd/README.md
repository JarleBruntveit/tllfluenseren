# Podkast – kapittel 1

Legg lydfilene her. Spilleren på kapittelsiden finner dem automatisk.

| Fil | Tema |
| --- | --- |
| `episode-1.mp3` | Lager og terminaler i samfunnet |
| `episode-2.mp3` | Lagerstyring og datasystemer |
| `episode-3.mp3` | Varemottak og kontroll |
| `episode-4.mp3` | Vareplassering og innrydding |
| `episode-5.mp3` | Ordre, plukk og klargjøring |
| `episode-6.mp3` | Godsterminaler og sortering |
| `episode-7.mp3` | Passasjerterminaler |

- Filtypen `.m4a` fungerer også (f.eks. `episode-1.m4a`).
- Bruk ikke `.wav` – filene blir for store. Gjør dem om til mp3 først.
- Episoder som mangler, vises ikke på siden.
- Lag lyden bare fra egenproduserte manus, ikke fra læreboka.
