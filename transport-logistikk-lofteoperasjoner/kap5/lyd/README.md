# Podkast – kapittel 5

Legg lydfilene her. Spilleren på kapittelsiden finner dem automatisk.

| Fil | Tema |
| --- | --- |
| `episode-1.mp3` | Regelverket for sikring av last |
| `episode-2.m4a` | Krefter, friksjon og tyngdepunkt – «Fysikken bak lastsikring på norske veier» (lagt inn) |
| `episode-3.mp3` | Låsing og blokkering |
| `episode-4.mp3` | Surring og surringsutstyr |
| `episode-5.mp3` | Ulike lasttyper og kombinert transport |

- Filtypen `.m4a` fungerer også (f.eks. `episode-1.m4a`).
- Bruk ikke `.wav` – filene blir for store. Gjør dem om til mp3 først.
- Episoder som mangler, vises ikke på siden.
- Lag lyden bare fra egenproduserte manus, ikke fra læreboka. `manus.md` i denne mappa er skrevet for å
  lastes opp som kilde i NotebookLM – én seksjon per episode.
